❓ FAQ

How does hosting work without a server?

Telegram supports two ways to receive updates: polling (your code asks Telegram repeatedly) and webhooks (Telegram pushes each update to an HTTPS URL). PyTeleHost Ultra runs your bot as a Python serverless function on Vercel — it wakes per update, replies in milliseconds and sleeps for free. That's real 24/7 hosting with zero idle cost.

My code uses polling (run_polling / start_polling). Can I host it?

Yes — use Polling mode with the included full panel: npm install && npm start locally, or the provided Dockerfile / Render config. It supervises your process forever with auto-restart, live logs, file manager and env secrets. Vercel itself is serverless, so long-running pollers belong on that stack.

Where do I get a bot token?

Open Telegram, message @BotFather, send /newbot, follow the prompts and copy the token (looks like 123456789:AAE…). Paste it in the Deploy Console and hit Validate.

Is my token stored?

No. Validation and webhook setup call Telegram's official API directly from the serverless function; the token is not persisted server-side. Your bot list lives only in your browser's localStorage.

Which frameworks are supported?

python-telegram-bot, aiogram 3, Telethon, Pyrogram and the raw Bot API. The built-in webhook brain needs zero dependencies — pure Python standard library.
