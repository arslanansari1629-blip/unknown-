Runtime engine

The server auto-detects your project language from its files. Anything with an interpreter can run — Python and Node.js are first-class, and you can always supply a custom start command.

Custom commands

A language not listed? Set the runtime to Custom, then give any start command. It runs inside /bin/bash in your project folder: ./my-binary --token $BOT_TOKEN, java -jar app.jar, swift run — whatever the host supports.

Guide

From zero to a permanently online Telegram bot in under three minutes.

Quick start
1

Create the bot on Telegram

Open @BotFather, send /newbot, choose a name and a username. He replies with a token that looks like this:

1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
2

Prepare your project

Your bot must read the token from an environment variable, not a hardcoded string. That way secrets stay out of your code.

BOT_TOKEN=1234567890:AAH...

Python: os.environ["BOT_TOKEN"] · Node.js: process.env.BOT_TOKEN

3

Deploy it here

Go to Deploy bot, upload the ZIP or paste the source, add BOT_TOKEN in the env box and press Deploy. Dependencies install automatically.

4

It stays online

The supervisor restarts your bot after a crash, a network error or a code exception. Watch live logs, send stdin, edit files and restart without ever touching a terminal.

FAQ
Do I need an account?

No. This panel has no login and no signup. Anyone with the URL can deploy — put it behind a private network or set the optional PANEL_TOKEN env if you need to lock it down.

Which languages are supported?

Python and Node.js are detected automatically, plus Bun, Deno, Ruby, PHP, Go, Rust, Java, .NET, Bash, Perl, Lua, Dart and Elixir. For anything else choose Custom and set your own start command.

Will my bot ever stop?

Only if you stop it. Crashes are followed by automatic restarts with exponential backoff, a watchdog re-launches dead processes, and running bots are resumed after a panel reboot.

Where are my files and token stored?

Under the panel's data/bots/<id> folder on the server that runs this app. They are never shared with third parties. Keep the server private if you host untrusted code.

Can I use a Telegram webhook?

Yes. Your bot gets a free port in the BOT_PORT env variable, but Telegram requires a public HTTPS URL. Polling mode (the default in most libraries) works out of the box and is recommended here.
